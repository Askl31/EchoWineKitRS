EchoWineKit

Installation et lancement d'EchoPAC sur Mac Apple Silicon — couche Wine + D3DMetal, sans machine virtuelle.

Composants (Wine) Préfixe Windows EchoPAC installé
Une tâche est en cours — les détails s'affichent dans la console en bas. Les demandes de mot de passe s'affichent dans le Terminal qui a lancé l'interface.

1Installer les composants

Rosetta 2, Homebrew, Wine « wine-crossover » (avec D3DMetal pour DirectX 11 → Metal) et winetricks. Une seule fois, ~10 min.

2Créer le préfixe Windows

Préfixe Wine isolé : Windows 10 64 bits, VC++ 2008, compilateur D3D, rendu via Metal.

3Installer ou mettre à jour EchoPAC

Indiquez le dossier du média d'installation (toute version d'EchoPAC convient — une mise à jour s'installe par-dessus l'existante). L'installeur GE s'ouvre dans sa propre fenêtre.

4Lancer EchoPAC

EchoPAC s'ouvre en plein écran dans sa propre fenêtre. Vous pouvez aussi créer une icône EchoPAC dans /Applications.

Désinstallation. « Désinstaller EchoPAC » supprime le programme, la copie du média et les entrées de registre — le préfixe est conservé pour une réinstallation. « Tout réinitialiser » supprime en plus le préfixe et les réglages. Dans les deux cas, les données d'examen stockées dans le préfixe sont supprimées : sauvegardez-les d'abord (bouton « Préfixe Windows »).
